# Sobrou+ — Boa comida. Mais valor. Menos desperdício.

Módulo do ALFA (sistema independente, banco próprio). Python 3 puro, sem instalar nada.

- Na internet (teste, dados fictícios): https://rmd-atendimento-web-production.up.railway.app/sobrou/
  app do cliente `/sobrou/` · painel `/sobrou/painel` · entregador `/sobrou/entregador`
- No ALFA: Laboratório de Módulos → Sobrou+ (abre cada perfil já logado, dados fictícios).
- `Sobrou+ (demonstracao).bat` — mesma demonstração, escolhendo o perfil.
- `Sobrou+ (real).bat` — banco real (vazio) neste computador e na rede Wi-Fi.
- `Testar Sobrou+.bat` — testes ponta a ponta.
- Ativar pagamento/WhatsApp: Painel (Central) → Integrações → colar as credenciais → Ligado.
- Logo oficial: copiar `SobrouPlus_Logo_Aprovada.png` como `web\static\img\logo.png`.
- Estado real de cada parte: `STATUS.md`. Regras do projeto: `COMBINADO_SOBROUPLUS.md`.
